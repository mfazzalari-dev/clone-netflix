# 🎬 Netflix Clone 

Clone da interface principal do serviço de streaming Netflix, desenvolvido com foco na prática de desenvolvimento front-end moderno.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estrutura semântica das páginas.
* **CSS3:** Estilização avançada com Flexbox e uso de variáveis.
* **JavaScript & jQuery:** Dinâmica da aplicação e controle do plugin de carrossel.
* **Owl Carousel 2:** Plugin jQuery utilizado para criar o carrossel de filmes e séries deslizante.

## 💻 Como executar o projeto
1. Clone este repositório para o seu computador.
2. Abra a pasta do projeto no **VS Code**.
3. Utilize a extensão **Live Server** para rodar o arquivo `index.html` localmente.
